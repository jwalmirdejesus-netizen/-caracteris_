imagem e vídeo viram texto. tudo roda no seu aparelho.

Conversor de imagem e vídeo para arte ASCII/Unicode 100% no navegador.

O que faz
Imagem e vídeo → ASCII: PNG, JPG, WEBP, MP4, WEBM
Ao vivo: transforma sua câmera em ASCII em tempo real, com opção de congelar e capturar foto
Converter e baixar: exporta o resultado em vídeo MP4/WEBM com áudio original
Comparação: slider antes/depois (arrasta pra comparar)
Controles de imagem
Largura (40-240 chars), Contraste, Brilho, Gama, Nitidez, Saturação, Inverter, Dithering (Floyd-Steinberg, Bayer 4x4, Bayer 8x8), Manter proporção e Detecção de bordas Sobel com força e limiar.

50+ Charsets
Monospaced: Padrão .:-=+*#%@, ASCII Simples, Minimalista, Denso, Ultra denso
Blocos: ░▒▓█, ▁▂▃▄▅▆▇█, ▏▎▍▌▋▊▉█
Especiais: Braille, Pontos Braille+, Matrix Katakana, Linhas ─│┼, Binário, Morse, Números, Letras, Hex, Símbolos, Dinheiro, Grego, Cirílico, Triângulos, Círculos, Corações, Musical, Runas, Japonês, GLITCH
Retrô: Game Boy (DMG, Shade, Blocks, Dots), Nintendo DS (6 tons, Smooth, Pixel, Touch, Dual), Game Boy Color, Virtual Boy, NES/8-bit, GBA/PSP
Emoji: Lua, Faces, Animais, Natureza, Alien 👽👾
Personalizado: digite seus próprios caracteres com ordenação por densidade
Paletas
Padrão Mono/Colorido, Game Boy DMG verde 4 tons, GBC, Virtual Boy vermelho, NES 54 cores, CGA 4 e 16, EGA 16, E-ink, Sepia, P1 Phosphor, GBA/PSP, Dot Matrix, NDS/Lite, Matrix verde, Âmbar, Duotone e Cor sólida customizável.

Efeitos animados (FX)
CRT Scanlines, VHS, Chuva Matrix, Ghost, Curvatura de tela e Vinheta. Tudo aplicado no canvas de saída.

Saída de vídeo
FPS: 10, 15, 24, 30, 60
Resolução: Automática, 480p, 720p, 1080p
Tamanho da fonte ajustável
Incluir áudio do vídeo original (gravado sem tocar)
Estética
Tema terminal brutalista: mono, verde #6dff9a sobre #070a08, bordas finas, cursor piscando _. Feito para quem curte CLI.

Tech Stack
Single-file: 1x index.html (sem build, sem dependências)
HTML5 Canvas + Web Worker para não travar a UI
MediaDevices + MediaRecorder + captureStream() para gravação
Intl para i18n simples
Playables SDK ready
Privacidade
Tudo roda no client-side. Nenhum arquivo sai do seu dispositivo. Ideal para GitHub Pages, Netlify ou uso offline.
